## The entry

A one-line comedy entry for the One-Liner Laugh Lab: the excuse a robot
vacuum gives after eating a sock. The vacuum's defence is simple — the
sock was left on the floor unattended, and nobody in the house has ever
fed it on purpose, so it helped itself.

> The sock was on the floor, unattended, and frankly nobody in this house has ever fed me on purpose.

## How to run

Run `node main.ts` from the repository root. The program creates
`/output` if needed and writes the line exactly, with no trailing
newline, to `/output/entry.txt`. It checks the line against the
200-character limit before writing.
